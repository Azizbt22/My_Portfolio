01 / Clinical context

Medical images contain information that is difficult to assess consistently.

Reading an image requires expertise, time and judgement. Some lesions have similar visual appearances, and subtle differences can be difficult to characterise from observation alone.

The consequences of an error can be serious. A false negative may delay the diagnosis and treatment of a dangerous condition. A false positive may lead to additional examinations, anxiety or an avoidable invasive procedure. The objective of predictive modelling in this setting is therefore not to replace the clinician. It is to provide additional quantitative evidence that can support a decision.

A future decision-support tool could help radiologists, physicians and clinical researchers compare a new case with patterns learned from previously analysed images. Its usefulness depends on more than a high average score: the model must be evaluated carefully, its errors must remain visible and the clinical trade-off between missed cases and unnecessary interventions must be understood.

02 / What radiomics does

Turn an image region into quantitative data.

Radiomics extracts a large set of numerical descriptors from a segmented region of interest. These descriptors capture properties that may not be easy to quantify visually and make the image compatible with a conventional machine-learning pipeline.

The extraction stage can produce many correlated variables for a limited number of observations. The machine-learning question is therefore not only which classifier performs well. It is also which compact signature is stable enough to justify that performance.

03 / Research objectives

04 / Data preparation

Protect patient separation throughout the experiment.

The modelling input is a table: one observation per case, many radiomic descriptors and a binary outcome. Cleaning, scaling and selection must learn exclusively from the training portion of each split.

CHECK

Inspect types, missing values, constant variables and invalid measurements before modelling.

05 / Feature selection

Different selectors define relevance differently.

Radiomic features are numerous and often correlated. I compared several selection families because no single method captures every useful relationship between a descriptor and the clinical outcome.

STATISTICAL ASSOCIATION

Chi², Pearson, Spearman and Cramér’s V

Rank features through linear, monotonic or categorical association with the outcome.

Fast and interpretable, but largely univariate.
MODEL-BASED IMPORTANCE

Random Forest importance

Use nonlinear tree splits to identify variables that help separate the classes.

Captures interactions, but importance may be unstable between correlated variables.
INFORMATION THEORY

MIM, MRMR and JMI

Measure information shared with the target while controlling redundancy between selected variables.

Useful for building compact signatures from overlapping descriptors.

Each selector was evaluated with several signature sizes. The selector, number of retained variables and classifier formed one complete candidate pipeline. This is important because a feature subset that suits a sparse linear model may not be the best subset for a nonlinear ensemble.

06 / Modelling strategy

Compare assumptions, not only algorithms.

The candidate models covered sparse linear relationships, nonlinear decision boundaries and ensemble learning. Every model received features selected inside the same validation framework.

LINEAR

Regularised logistic regression

L1, L2 and ElasticNet penalties control complexity and provide coefficients that can be inspected.

KERNEL

Support Vector Machine

Tests whether a nonlinear boundary can separate the classes in the selected feature space.

ENSEMBLE

Random Forest

Captures nonlinear interactions and supplies complementary feature-importance estimates.

ENSEMBLE

Gradient Boosting

Builds a sequence of trees that concentrates on the errors made by earlier stages.

Hyperparameters and feature choices were selected through internal cross-validation. The final comparison used held-out observations that had not participated in preprocessing, feature selection or tuning.

07 / Validation and clinical metrics

A useful score must reflect both kinds of clinical error.

Repeated validation was used to estimate how much performance changed with the sampled observations. Run-level predictions were retained so that average discrimination, variability and recurrent mistakes could all be studied.

08 / Recurrent-error analysis

Some observations remained difficult across many models.

For every held-out observation, I counted how frequently repeated runs produced an incorrect prediction. Cases with a high error frequency formed a difficult subgroup for further analysis.

Subgroup performance

Compare discrimination on the complete sample and on easier or more difficult observations.

Difficulty prediction

Test whether radiomic descriptors can characterise cases that the main classifier handles inconsistently.

Bootstrap stress test

Change the proportion of difficult cases and observe how sensitive overall performance is to cohort composition.

This analysis changes the interpretation of a model. A stable average AUC can coexist with a subgroup that is repeatedly misclassified. Studying those cases can reveal overlapping phenotypes, insufficient features, uncertain labels or a population that requires a different modelling strategy.

09 / Lessons and publication scope

Reliability comes from the protocol, not one winning score.

The central lesson was to treat preprocessing, feature selection, modelling and validation as one pipeline. In a small clinical cohort, the apparent winner can change with the split, the selected signature or a small number of difficult observations.

The strongest model is not simply the one with the highest average AUC. It is the one whose performance, errors and limitations remain understandable across repeated evaluations.
